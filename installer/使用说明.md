# Web Chat for DSH · 使用说明

在 DeepSeek Harness Desktop 左侧栏加一个 Web Chat 面板，下拉可切换
**DeepSeek / ChatGPT / Gemini / Claude** 四个官方网页版。

## 安装

1. 先把 DeepSeek Harness 完全退出（⌘Q）。
2. 双击本磁盘映像里的 **安装 Web Chat.command**。
   - 若 macOS 提示「无法验证开发者」：右键该文件 →「打开」→ 再点「打开」。
3. 重新打开 DeepSeek Harness。
4. 左侧栏「新会话」下方出现 **Web Chat**，点开后在顶部下拉里选站点、登录。

安装位置：`~/.dsh/local-plugins/dsh-deepseek-webchat`；
profile 配置会先备份再修改。

## 卸载

退出 DeepSeek Harness，双击 **卸载 Web Chat.command**。

## 说明与限制

- 仅支持 DeepSeek Harness **桌面版**（依赖桌面端原生 browser guest）。
- 「引用上下文」与右键接力对 **四个站点都可用**：引用块会填入当前站点的输入框
  （单行/多行分别适配，已有草稿会被替换）；会话绑定与登录快照恢复仍只对 DeepSeek 生效。
- 同一次运行内各站点登录态都在；**应用重启后**：DeepSeek 会自动恢复登录，
  ChatGPT / Claude / Gemini 可能需要重新登录（登录凭据在 HttpOnly cookie 里，
  插件读不到），且 Google 登录可能被内嵌 WebView 拦截。
- 本插件为第三方修改版，基于 [Ckarefulon/dsh-deepseek-webchat](https://github.com/Ckarefulon/dsh-deepseek-webchat)
